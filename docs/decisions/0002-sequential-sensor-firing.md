# 0002. 초음파 센서 순차 발사

- 상태: 채택됨
- 날짜: 2026-08-10

## 맥락

JSN-SR04T는 빔 각도가 약 45~75°로 넓다. 4개를 차량 뒤쪽에 나란히 달면 각 센서의
측정 영역이 크게 겹친다.

4채널을 동시에 발사하면 CH1이 쏜 초음파의 반사파를 CH2가 자기 것으로 착각해 받는다.
결과는 무작위로 틀린 거리값이고, 그게 실제보다 **가깝게** 나오면 헛경보, **멀게**
나오면 진짜 장애물을 놓친다. 어느 쪽이든 위험하다.

동시 발사의 유일한 장점은 갱신 주기를 4배로 줄일 수 있다는 것이다.

## 결정

**한 번에 한 채널만 발사한다.** 해당 채널의 에코를 받거나 타임아웃될 때까지 다음
채널의 Trig를 올리지 않는다.

순서는 CH1 → CH2 → CH3 → CH4 라운드로빈. 채널당 슬롯 25ms, 4채널 한 바퀴 100ms로
BLE 전송 주기 10Hz와 맞춘다. 에코 타임아웃은 20ms(≈340cm)로 슬롯 안에 들어오게 잡고,
남는 약 5ms는 잔향이 가라앉는 시간으로 쓴다.

에코 대기는 `pulseIn()` 같은 블로킹 호출이 아니라 **인터럽트 + `micros()` 타임아웃**
으로 구현한다. `loop()`가 멈춰 있으면 부저 타이밍과 BLE 처리가 같이 밀린다
(→ 개발 원칙 3).

## 결과

- 각 채널의 실효 갱신 주기는 10Hz다. 사람이 후진하는 속도(빨라야 초당 1~2m)에
  대해서는 충분하다. 100ms 동안 최대 20cm 정도 움직인다.
- 4채널 값이 완벽히 동시각은 아니다. 한 패킷 안의 `d1`과 `d4`는 최대 75ms 차이가
  난다. 이 정도 차이는 표시상 문제가 되지 않으므로 보정하지 않는다.
- 센서를 더 붙이려면 슬롯을 줄이거나 갱신 주기를 늘려야 한다. 채널 수와 응답성이
  직접 상충한다.
- 한 채널이 계속 타임아웃되면 그 슬롯 20ms가 매 사이클 낭비된다. 그래도 순서를
  건너뛰지 않는다 — 센서가 다시 살아났을 때 감지해야 한다.

## 검토한 대안

- **동시 발사**: 상호간섭으로 기각. 이 프로젝트에서 데이터 정확도는 응답성보다 우선한다.
- **대각선 채널만 동시 발사 (CH1+CH3, CH2+CH4)**: 갱신 주기를 50ms로 줄일 수 있지만,
  차량 폭에 4개를 배치하면 대각선 쌍도 빔이 겹친다. 실측으로 간섭이 없다는 게 확인되면
  그때 새 ADR로 다시 검토한다.
- **센서별 다른 주파수 사용**: JSN-SR04T는 40kHz 고정이라 불가능하다.
